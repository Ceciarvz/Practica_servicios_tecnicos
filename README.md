# Servicios Técnicos
## Descripción
Aplicación web para administrar clientes, técnicos y servicios técnicos.
## Tecnologías
- Frontend: React, JavaScript y CSS
- Backend: Python y Flask
- Base de datos: MySQL
- Pruebas de API: Thunder Client
## Requisitos
- Python y pip
- Node.js y npm
- MySQL
- Git
## Configuración
1. Crear la base de datos `tecnico`.
2. Ejecutar el script SQL del proyecto o crear las tablas requeridas.
3. Configurar las variables de entorno localmente.
4. Instalar dependencias del backend.
5. Instalar dependencias del frontend.
## Ejecución
Backend:
1. Activar el entorno virtual.
2. Ejecutar el punto de entrada de Flask.
Frontend:
1. Entrar a la carpeta frontend.
2. Ejecutar `npm run dev`.
